# HOLISTIC Remote Update & Links System (`holistic-update`)

مستودع التحكم الخارجي بتحديثات وروابط تطبيق **HOLISTIC** (`MujahidMods/holistic-update`).

## الملفات الأساسية في المستودع
1. **`update.json`**: ملف الإعدادات الرئيسي الذي يقرأه التطبيق تلقائياً عند التشغيل للتحقق من وجود إصدار جديد وتحديث روابط التواصل (واتساب، تيليجرام، انستقرام، فيسبوك، الموقع).
2. **`update.html`**: صفحة ويب تفاعلية لعرض تفاصيل التحديث وتحميل ملف الـ APK.
3. **`links.html`**: صفحة جميع روابط التواصل الرسمية مع المطور.
4. **`about.html`**: صفحة تعريفية حول التطبيق والمطور.

## طريقة التحكم بالتحديثات من `update.json`
- **الوضع العادي (بدون إشعار تحديث):** اجعل `"version_code": 1` و `"latest_version": "1.0"`.
- **تفعيل تحديث اختياري (بإشعار وزر لاحقاً):** ارفع `"version_code"` إلى `2` (أو أعلى من نسخة التطبيق المثبتة) واجعل `"force_update": false`.
- **تفعيل تحديث إجباري (قفل التطبيق حتى يتم التحديث):** اجعل `"force_update": true` مع `"version_code": 2`.
